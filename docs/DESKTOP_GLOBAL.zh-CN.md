# Codex 桌面端与终端的全局模式

本版本把 Global 模式接进 `START.command`：启动稳定本地网关、建立全局控制队列、配对一个持续工作的原生控制器、验证真实原生请求，再展示全局配置差异。独立单会话 Router 仍可从菜单使用。

这是有明确验证条件的试用流程。代码已经接通；发布包本身不代表你的 Mac 已完成接管。`production_ready` 保持 false。真实 Mac、Google 连接器、桌面新线程，以及 TOML 真解析器验收，需要在授权的实际环境完成。

## 第一次使用

1. 双击 `START.command`，选择菜单中的 Global start。已有设置会复用；首次运行会要求选择专用 Drive 文件夹、现有凭据、工作目录及默认模型和推理档位。安装专用 Python 环境时会单独征求同意，其中包括固定版本 `tomlkit 0.13.3`。
2. 选择桌面和终端实际共用的 `CODEX_HOME`。程序核验终端 CLI 和桌面内置 CLI 的版本及文件内容，当前要求两者均为 `codex-cli 0.159.2`。不推测其他账号目录或 profile 的设置。
3. 确认本次有界 Google 控制流程。先成功占用 `127.0.0.1:43187`，才会进行凭据刷新和资源创建。一次激活最长四小时，最多三个原生子任务，其中一个用于预检，另外两个可供新的桌面线程使用。平台剩余槽位可能更少。
4. 复制并发送一次私有 `DOTS2CODEX_GLOBAL_JOIN_V1` 到 Dots。这个消息启动的是持续监督队列的全局原生控制器。每个新线程的模型和推理档位会分别验证、分别创建子任务。Python 不能创建或自动唤醒原生任务。
5. 控制器加入后，程序自动提交一次很小的原生预检。必须完成该激活的签名队列、独立子任务、v3 JOIN、双向原始文件探测、不可变 pin 和经网关返回的准确随机回应，才能进入配置确认。
6. 核对显示的 `CODEX_HOME/config.toml` 目标和具体受管设置，再确认写入。证据必须仍新鲜，网关和控制器必须仍活跃，原始配置和待写配置的散列都必须匹配。只启动监听器或更改一个布尔值不能通过此门槛。
7. 完全退出并重新打开 Codex 桌面端，创建新线程工作。新启动的终端 CLI 使用同一 `CODEX_HOME`。旧线程、恢复的历史会话、profile、命令行覆盖或组织策略，可能保留或指定其他 provider；本流程不会改写历史线程。

若配对或预检仍进行中，重新打开 Global start 可以继续同一次激活，不会重复创建控制器或替换原生子任务。配置证据超过五分钟后，可明确要求在同一个已绑定子任务上刷新预检；新请求延续完整历史，未知执行结果不能重试。预检、控制器及激活都受原有截止时间和配额约束。

## 停止和恢复

Global status 显示本地监督程序、控制器、线程数及配置事务状态。程序监听端口不等于控制器 ready，也不证明桌面新线程已经验证。

Global stop 立即写入停止意图并关闭本次激活的准入，再尝试关闭签名队列和各线程控制。网络故障可能使远端关闭结果不确定；本地进程停止不代表原生任务已停止，还需在 Dots 结束这次有界控制器。未知原生任务不会被算作可复用容量。

Global restore 使用私有备份撤回本次受管设置。原文件未被其他编辑器改动时按原字节恢复；存在其他编辑时，只在受管值和注释均未发生冲突时合并恢复。冲突会停止而不覆盖。即使配置写入之后、界面成功标记之前发生崩溃，也能从事务日志找到并恢复。恢复后需重新打开客户端。

## 原生控制器的边界

控制器运行说明见 [GLOBAL_NATIVE_CONTROLLER.md](GLOBAL_NATIVE_CONTROLLER.md)。JOIN 只授权指定队列、文件夹、生命周期和已审阅协议，不授予任意文件操作、OAuth、共享、更宽权限或下一次激活的永久授权。每条桌面线程在首次有效请求之前固定模型与推理档位。

本版本不宣称无限线程、永久后台原生服务、自动唤醒或旧线程无缝迁移。首次新线程会有最多 180 秒的配对等待，使用有效 Responses 事件维持客户端流；超时或配对前断开不保存提示词供后来执行。已有执行结果不明时禁止自动重放。

## 验证状态

离线测试覆盖真实本地网关和独立 facade、签名队列与原生计划的仿真端口、控制器与线程隔离、工具相关性、未知副作用、配置恢复和启动器生命周期。测试中的仿真原生收据不是现场真实模型证明。当前环境没有获准安装 tomlkit；真实解析器测试保持明确跳过，不能把它们算作通过。选择某个桌面可执行文件和 CODEX_HOME 本身，也不能证明运行中的桌面已采用这个目录；仍需重启后观察一个实际新线程的路由收据。
